Before you add a PC

1
Install VNC Server

Make sure a VNC server such as TightVNC is installed and running on the remote computer.

2
Check Network Access

The remote computer must be reachable from the RemoteDesk server.

3
Verify VNC Port

Ensure the VNC server is listening on the configured port, normally 5900.

Security

In production, remote connections should be authenticated and encrypted.
